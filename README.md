# 🖥️ Computer Architecture Projects – University of Tehran

This repository contains a collection of projects related to **Computer Architecture**, implemented as part of the coursework at the **University of Tehran**.  
Each project focuses on different aspects of processor design and computer arithmetic, using **Verilog** or **SystemVerilog** for simulation and implementation.

---

## 📁 Project Structure

| Folder               | Description                                                                 |
|----------------------|-----------------------------------------------------------------------------|
| 🔢 **Computer Arithmetic**    | Design and simulation of a 10-bit sequential division circuit with control flags |
| 🧮 **Single Cycle Risc_V**    | Implementation of a single-cycle RISC-V processor supporting all major instruction types |
| 🚀 **Pipeline Risc_V**        | Design of a pipelined RISC-V processor with hazard detection and 5-stage execution |
| ⏱️ **Multi Cycle Risc_V**     | Multi-cycle RISC-V processor with staged instruction execution and optimized hardware reuse |

---

## 🔧 Technologies Used
- `Verilog` / `SystemVerilog`
- `ModelSim`, `Vivado`, or other FPGA simulation tools
- Testbenches and waveform analysis for simulation verification

---

## 📦 Deliverables for Each Project
- ✅ Processor/System Design in Verilog
- ✅ Testbenches and sample simulation results
- ✅ Project documentation and architecture explanation
